# Executive-Summary Format (stakeholders)

Layout: project header, Executive Summary
paragraph, Overall Assessment table (all 11 areas × Passed|Good|Fix), Finding
Summary by Category (count + Critical/High + status), Prioritized Findings table
(severity-sorted), and the Remediation Guide appendix (one numbered step per
`meta.remediation_steps` entry). Produced by `reportgen/exec_summary.py`.
